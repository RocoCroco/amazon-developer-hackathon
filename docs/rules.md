# Devpost rules and judging criteria (T0.0)

Sources: https://amazonappdev2026.devpost.com/ and /rules (read 2026-10-01 via summarized fetch; re-check the exact wording on the page before submitting).

## Alexa+ track
- Build "a self-hosted MCP server (spec 2025-11-25 or later, Streamable HTTP) or an Agent Skill".
- Developers new to MCP may instead build a **simulated Alexa+ experience in a web app**. A simulator is therefore acceptable; our plan (real MCP server + simulator) fits.
- The code must use the required technology **at runtime**, not just mention it in docs; the demo video must show it working.
- Prizes: Alexa+ 1st place $25,000 + $15,000 AWS credits. Mini challenges ($5,000 each): AWS Builder, Open Source.

## Dates (PT)
- Submission: Aug 31 2026 10:15 AM - **Oct 23 2026 12:00 PM**. Judging Nov 9-20. Winners Dec 3.

## Submission deliverables
- Working application; text description.
- GitHub repo: **public with an open-source license OR private shared with the judging team**.
- Demo video < 3 min, YouTube/Vimeo, English, showing the working project.
- Product feedback on every tool/API/SDK used (FEEDBACK.md).
- Track and mini-challenge selection.
- Optional friction log (up to 10% bonus) (FRICTION_LOG.md).

## Judging (equally weighted)
1. Tech implementation (effective use of required APIs/SDKs)
2. Design (complete, coherent, intuitive experience)
3. Potential impact (credible need beyond the hackathon)
4. Quality of idea (creative, understands the ecosystem)
