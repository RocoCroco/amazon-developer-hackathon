# How this project was built

Working files from the build, kept for transparency. Recall Guardian was built by an AI coding agent (Claude Code)
working from a written spec and task list, with a human making the product decisions; the agent's rules are in
[CLAUDE.md](../../CLAUDE.md).

| File | What it is |
|---|---|
| [SPEC.md](SPEC.md) | The product spec the build started from |
| [TASKS.md](TASKS.md) | The task list, checked off as the work was done |
| [PROGRESS.md](PROGRESS.md) | The session hand-off note (current task, next step) |
| [BLOCKERS.md](BLOCKERS.md) | Things that needed the human: accounts, keys, decisions |
| [judge-review.md](judge-review.md) | A strict self-review against the judging criteria |
| [manual-checklist.md](manual-checklist.md) | Manual checks run before the demo |
| [video-script.md](video-script.md) | The demo video script: presenter lines, demo recording, motion graphics brief |
| [devpost-submission.md](devpost-submission.md) | The Devpost submission text |

Problems met along the way and how they were solved: [FRICTION_LOG.md](../../FRICTION_LOG.md). Feedback on every
tool and service used: [FEEDBACK.md](../../FEEDBACK.md).
